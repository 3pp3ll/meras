# مِراس

منصة تعليمية للسوق المالية السعودية. ثلاثة مسارات (المستثمر المبتدئ، المتداول، المبرمج)، كل مسار خمس درجات، مع سجل تداول وحاسبات وقاموس.

المحتوى تعليمي فقط، وليس توصية بشراء أو بيع أي ورقة مالية.

## التشغيل

الموقع صفحة واحدة ثابتة تنشر عبر GitHub Pages:

1. Settings ثم Pages.
2. في Source اختر Deploy from a branch، والفرع `main` والمجلد `/ (root)`.
3. بعد دقيقة يفتح الموقع على `https://3pp3ll.github.io/meras/`.

## تثبيتها كتطبيق

- آيفون (Safari): زر المشاركة ثم "إضافة إلى الشاشة الرئيسية".
- أندرويد (Chrome): القائمة ثم "تثبيت التطبيق".
- الكمبيوتر (Chrome أو Edge): أيقونة التثبيت في شريط العنوان.

## المزامنة والأسعار الحقيقية

التقدم وسجل التداول والأسعار محفوظة في مستودع خاص منفصل (`meras-data`)، وهذا المستودع ما فيه أي بيانات. الربط من داخل المنصة: حسابي ثم "المزامنة والأسعار".

## الملفات

| الملف | وش فيه |
|---|---|
| `index.html` | المنصة كاملة (ناتج البناء، لا تعدله بيدك) |
| `sw.js` و `manifest.webmanifest` و `icons/` | ملفات التطبيق والعمل بدون نت |
| `src/content.js` | الدروس والقاموس والمسارات |
| `src/app.js` | الصفحات والمنطق |
| `src/sync.js` | المزامنة وقراءة الأسعار |
| `src/style.css` | الهوية والتصميم |
| `build.sh` | يجمع ملفات `src` في `index.html` |

بعد أي تعديل في `src` شغّل `./build.sh` ثم ارفع التغييرات.
